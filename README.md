A responsive static HTML/CSS/JavaScript portfolio. No build or package installation required.

## Deploy to Vercel
1. Commit all files in this folder to your GitHub `Portfolio` repository (preferably a new branch for review).
2. In Vercel, import the GitHub repository, or update the existing Vercel project's Production Branch after reviewing.
3. Framework Preset: **Other**; Build Command: leave blank; Output Directory: `.` (repository root).
4. Deploy. Vercel will display the new live URL.
